    2. Open Apps Script — inside the spreadsheet click Extensions → Apps Script. A code editor opens.

    3. Paste the code below, replacing everything in the editor. Click Save (Ctrl+S).

    4. Deploy → New Deployment → Web App. Set "Execute as: Me" and "Who has access: Anyone". Click Deploy. Copy the web app URL and paste it above.
